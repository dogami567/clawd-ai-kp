# AI-KP 项目规划 v0.1（默认版）

> 这份是默认规划稿，用来把当前已经拍板的方向、规则边界、场景预期、开发顺序先收成一份可改文档。
> 
> 先有，再慢慢改，不追求一次写死。

## 1. 项目目标

`AI-KP` 的目标不是做一个只会播报规则的 TRPG 机器人，而是做一个能在聊天里实际带团、会记状态、会接玩家脑洞、会用主持人口吻演绎的 `AI Keeper`。

当前默认目标：
- 以 `Call of Cthulhu 7th Edition` 为规则基线
- 先做 `单群 / 单会话 / 单剧本场景`
- 先把“能跑起来”做稳，再逐步补深度

## 2. 产品形态

### 2.1 核心引擎
负责：
- 角色卡
- NPC 卡
- 场景状态
- 检定系统
- 行动裁定
- 线索 / 事件 / 时间推进
- 结团存档

### 2.2 聊天接入层
负责：
- 收玩家消息
- 路由动作到核心引擎
- 组织输出文本
- 管理群 / 会话 / 权限 / 限流

### 2.3 当前路线
- 先做 `core`
- 后做 `adapter / plugin`
- 首版不先做复杂 UI，不先做多平台通吃

## 3. 规则范围（v0.1）

### 已确定
- 规则基线：`CoC 7th Edition`
- 检定核心：`d100`
- 成功等级：
  - `regular`
  - `hard`
  - `extreme`
  - `critical / fumble`（先做简化）
- 失败处理：`fail forward`

### 首版要覆盖
- 车卡（Quick-Fire 先行）
- 派生属性（HP / MP / SAN / Build / Damage Bonus / MOV）
- 探索
- 交谈
- 用道具
- 高风险动作
- 偷窃
- 跟踪
- 战斗一轮最小版
- SAN 检定最小版

### 暂缓
- 完整追逐系统
- 完整法术系统
- 大规模战斗
- 复杂载具规则
- 多模态演出（图/音）
- 全规则书复刻

## 4. 体验目标

### 4.1 玩法感受
- 玩家说自然语言，AI-KP 尽量都能接住
- 不轻易空气墙
- 越界动作优先转成世界内后果
- 失败不把剧情掐死
- 玩家的小作文要值钱

### 4.2 口吻目标
- 说话像桌边在带团的人
- 有前摇，有停顿，有掷骰感
- 麦麦口吻要活，不回通用 GPT 腔
- 暗骰要写出来，但不能每次同一句复读

### 4.3 世界感目标
- NPC 不是吐情报机器
- NPC 要有：
  - 穿着
  - 财富
  - 身上物品
  - 行动规律
  - 警觉度
  - 社交偏好
  - 知识层级
- 玩家偷、跟踪、威逼、哄骗，都要能得到不同反应

## 5. 数据结构规划

### 5.1 调查员卡 `investigator-card`
至少包含：
- 姓名
- 年龄
- 职业
- 人设一句话
- 属性
- 派生值
- 技能
- 物品
- 状态

### 5.2 场景状态 `scene-state`
至少包含：
- 场景类型
- 时间推进
- NPC / 玩家参与者
- 线索
- 事件
- 暴露 / 压力 / 危险度
- 当前可行动作

### 5.3 检定事件 `check-event`
至少包含：
- 行动类型
- 谁在做
- 用什么技能
- 难度
- 掷骰结果
- 成败等级
- 后果
- 状态变更

### 5.4 NPC 卡 `npc-card`
至少包含：
- 身份与外观
- 穿着
- 财富等级
- 身上物品与可偷窃物
- 行动规律
- 跟踪难度
- 警觉触发条件
- 社交偏好
- 知识分层（不同成功等级吐不同内容）

## 6. 预期场景类型

默认先做这些：
- 调查型单幕（主）
- 社交套话型场景
- 受限空间探索型场景
- “碰一下就会有后果”的危险物场景

首个默认模板：
- 老建筑 / 教堂 / 废宅 / 旅馆 / 医院 这种容易做线索链和恐惧感的场景

## 7. 玩家常见行为清单（优先支持）

### 基础类
- 看
- 听
- 问
- 走
- 记录
- 用道具

### 社交类
- 安抚
- 套话
- 骗
- 魅惑
- 威逼
- 贿赂

### 风险类
- 强闯
- 翻找
- 撬开
- 偷
- 抢
- 跟踪
- 尾随
- 躲藏

### 战斗类
- 攻击
- 闪避
- 反击
- 借环境做动作
- 临时脑洞加成

## 8. NPC 反应系统（默认思路）

对同一个 NPC，至少要区分：
- 你是正常问
- 你是顺着他软处说
- 你是在吓他
- 你在收买他
- 你在跟踪他
- 你在偷他东西

同样一条信息，不同方式不该给一样的结果。

## 9. 开发顺序（默认）

### 阶段 1：底层骨架
- 车卡
- 检定
- 派生属性
- 基础场景状态

### 阶段 2：动作裁定
- explore
- talk
- use_item
- risky_action

### 阶段 3：NPC 卡接入
- 交谈按卡吐情报
- 偷窃按卡判物品与发现
- 跟踪按卡判行动规律

### 阶段 4：单幕 demo
- 固定场景
- 固定 NPC
- 固定线索链
- 固定危险节点
- 可跑一小段完整试玩

### 阶段 5：接聊天入口
- 命令/API 稳定
- 再接 OneBot / 插件层
