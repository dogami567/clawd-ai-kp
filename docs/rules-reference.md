# AIKP 规则参考入口（固定）

本项目默认规则基线：**Call of Cthulhu 7th Edition（CoC 七版）**。

## 1) 官方主规则书（优先）
- Keeper Rulebook（Chaosium 官方）：
  https://www.chaosium.com/call-of-cthulhu-keeper-rulebook-hardcover/

## 2) 官方玩家扩展书（辅助）
- Investigator Handbook（Chaosium 官方）：
  https://www.chaosium.com/call-of-cthulhu-investigator-handbook-hardcover/

## 3) 可选数字版入口（用于快速检索）
- Keeper Rulebook PDF（DriveThruRPG）：
  https://www.drivethrurpg.com/en/product/150997/call-of-cthulhu-7th-edition-keeper-s-rulebook

## 4) 官方规则 wiki（实现时优先翻）
- CoC7 游戏系统总览（奖励/惩罚骰、对抗检定、group Luck、pushed rolls）：
  https://callofcthulhuwiki.chaosium.com/game-system.html
- 调查员创建：职业与技能：
  https://cthulhuwiki.chaosium.com/investigators/step-three-occupation-and-skills.html
- HP / 重伤 / 临死 / 治疗：
  https://callofcthulhuwiki.chaosium.com/rules/hit-points-wounds-and-healing.html
- SAN 与疯狂：
  https://callofcthulhuwiki.chaosium.com/rules/sanity.html

## 5) 社区速查（官方没写全时再补）
- Roll20 Sample Occupations（样例职业入口，便于对照常见职业面）：
  https://roll20.net/compendium/coc/Sample%20Occupations
- mythos.wiki CoC7 Cheat Sheet（多人检定 / 战斗 / 重伤等速查）：
  https://mythos.wiki/index.php/Call_of_Cthulhu_7th_Edition_Cheat_Sheet

## 使用约定
- 后续 AIKP 的规则实现、补充、争议解释，一律以 CoC 七版为准。
- 旧版（如 CoC 5版）仅用于历史参考，不作为默认实现依据。
- 若出现“可选规则/家规”，在文档中显式标注，不混入基础规则。
