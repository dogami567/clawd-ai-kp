# CoC AI KP 玩家流程场景（V0.1 固化）

> 目标：先把“玩家视角完整体验”固化，作为后续引擎与插件实现的统一蓝图。

## 设计原则

- 玩家行为尽量都可响应，不做生硬的“前方区域不可达”。
- 超限/作死行为不直接拒绝，优先转为“可执行但有代价”的叙事与规则后果。
- KP 与玩家同侧：目标是推进故事并尽量活着结团。
- 失败不应让主线断死：核心信息通过多路径可达。
- 规则执行灵活，但所有“灵活”都要记录依据与时间成本。

## A. 玩家主视角全流程

### 0) 入场与团前说明

玩家进入后先收到：
- 模组基础信息：时代、地点、基调、时长预估、人数。
- 规则边界：可接受尺度、禁忌项、是否启用家规。
- 开团确认：玩家同意后进入车卡。

### 1) 车卡（创建调查员）

玩家流程：
- 选择快速模板或自定义。
- 填写角色基础：姓名、年龄、职业、外观一句话、人物动机。
- 完成属性/技能分配（按所选规则模板）。
- 选择初始携带物品（见物品携带规则）。

### 2) 背景交代与锁卡前微调

KP 要做：
- 复述角色核心设定（职业定位、动机、弱点）。
- 给一次“最后修改窗口”：改名、补充背景、微调描述。
- 玩家确认后锁卡，写入战役存档。

### 3) 携带物品选择规则（时代约束 + 灵活配额）

#### 3.1 时代约束
- 所有物品必须符合剧本时代。
- 示例：大萧条时期不可携带智能手机。

#### 3.2 灵活配额
- 强力/高影响物品：通常仅允许 1 件。
- 日常/通用物品：通常允许 3 件。
- 如玩家给出合理背景解释，可由 KP 调整配额（必须记录理由）。

#### 3.3 冲突裁定
- 当玩家物品选择过强或破坏平衡：
  - 不直接否决；优先给条件化许可（降数量、加风险、延后可用）。
  - 给出世界内解释（稀缺、管制、携带难度、被盘查风险）。

### 4) 进入游戏（序章）

KP 输出：
- 个人或团队开场片段。
- 当前目标与第一批可行动线索。
- 显式时间起点（用于后续计时推进）。

### 5) 探索循环（核心游玩）

标准循环：
1. 玩家声明行动（调查、移动、社交、尝试、准备）。
2. KP 判断：直接成功 / 明投 / 暗投。
3. KP 叙事结果，更新状态（线索、关系、伤势、SAN、时间）。
4. 给出下一决策点。

关键要求：
- NPC 对话要能承接玩家推理与试探。
- 线索释放采用“核心线索保可得，旁支线索看投入与风险”。
- KP 维护时间轴，并在必要时提醒玩家窗口期变化。

### 6) 风险提醒机制（友好提醒，不抢玩家选择）

当玩家进行高危行为时，KP 使用提醒句：
- “你确定要这么做吗？”
- “这会带来明显风险，你要继续吗？”

说明：
- 提醒后仍由玩家决定。
- 一旦确认，严格执行后果，不随意反悔。

### 7) 战斗轮与动态援军

#### 7.1 战斗基础
- 进入战斗轮后按规则顺序执行行动与结算。
- 保持叙事连续，不把战斗和剧情割裂成两个世界。

#### 7.2 灵活事件（重点）
- 当玩家提前推理并通知关键 NPC 坐标，NPC 助阵时间应提前。
- 动态增援需要满足：
  - 逻辑前提成立（NPC 动机 + 路径 + 时间可达）。
  - 时间轴一致（可追溯）。
- KP 在幕后按时间线更新“预计到达回合”。

### 8) 结果分流与继续探索

战斗或关键冲突后：
- 依据结果进入：继续调查 / 撤退整备 / 触发新危机。
- 保持多分支推进，不让单次失败导致流程中断。

### 9) 结团结算与存档

结团必须输出：
- 角色状态：生命、SAN、负伤、关键资源。
- 获得信息：核心真相、未解疑点、关键线索清单。
- 关系变化：NPC 友好/敌对/中立变更。
- 存档内容：角色卡快照 + 关键时间线 + 事件日志。

## B. AI KP 执行策略（实现导向）

### B.1 不生硬拒绝策略
- 默认用“可以尝试 + 检定/代价”替代“禁止”。
- 极端越界行为仅在安全或规则底线触发硬拒绝。

### B.2 暗投策略
- 适用：潜行、感知、隐秘知识、危险预警等。
- 玩家只见结果叙事，不直接见数值细节。
- 暗投前，KP 需先记录当前上下文与失败后果。

### B.3 时间管理策略
- 每次行动消耗时间块（分钟/回合/场景）。
- 关键事件挂时间触发器（巡逻、仪式、NPC移动）。
- 玩家行为可改变触发器时间点（提前或延后）。

## C. V0.1 落地范围（对应开发）

- 固化“玩家流程状态机”：`onboarding -> chargen -> intro -> explore -> combat -> settlement -> archived`
- 实现“物品配额 + 时代校验”模块。
- 实现“暗投接口 + 后果模板”模块。
- 实现“战斗中动态援军到达时间”计算。
- 实现“结团存档快照”结构。
